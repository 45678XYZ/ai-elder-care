切「身分」會先清掉本機狀態再種一份對應的登入狀態，所以每次切身分等於從乾淨狀態開始， 連結家人與初次設定填過的東西都會歸零。要用真正的流程（註冊 → 初次設定 → 驗證碼 → 登入） 就切到「未登入」從登入／註冊頁走；demo 驗證碼固定 123456。
這些狀態存在瀏覽器的 Local Storage（key 前綴 flutter.）， 要完全從頭來過也可以開無痕視窗，或在 DevTools 清掉 Local Storage。
需要用 file:// 直接開這一頁時身分切換會失效（iframe 與本頁不同源， localStorage 不共用）——請用靜態 server 提供 build/web。
