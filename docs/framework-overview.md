# 客照e點通 — 系統架構概覽

本文件是 `docs/framework.md` 的易讀版本，將底層技術細節抽象為高階概念，適合初次了解系統的人閱讀。

---

## 系統是什麼？

「客照e點通」是一套 AI 長者照護系統，讓長輩用語音（國語或客語）與 AI 聊天，系統自動記錄生活狀況並通知照護者。

## 三大模組

| 模組 | 功能 | 使用者 |
|------|------|--------|
| A — 語音互動陪伴 | 免手持語音對話，AI 能記住長輩說過的話、了解日常習慣 | 長者 |
| B — 生活記錄與智慧摘要 | 自動從對話中提取生活事件、管理例行公事、產生每日摘要 | 系統自動 |
| C — 照護者資訊介面 | 查看長輩狀況、設定提醒、瀏覽統計 | 照護者（家人） |

---

## 技術架構簡述

### 前端

- **Flutter App**：單一 App，登入後依角色顯示長者模式或照護者模式

### 後端

- **AWS Lambda (Python)**：所有業務邏輯以無伺服器函式執行
- **API Gateway**：統一的 API 入口，處理認證與路由
- **Cognito**：帳號管理與登入驗證
- **DynamoDB**：資料庫（NoSQL）
- **Terraform**：基礎設施以程式碼管理

## 對話流程

```
長者說話 → App 錄音 → 後端語音辨識 → AI 生成回覆 → 語音合成 → App 播放
```

### 即時處理 vs 批次處理

系統採「混合式」設計：

| 處理時機 | 內容 | 原因 |
|----------|------|------|
| 即時（對話中） | 例行公事的建立/修改/完成、高風險安全事件 | 需要馬上生效或通知 |
| 批次（對話結束後） | 一般生活事件（飲食、活動、睡眠等） | 不急迫，可以整理後再呈現 |

### 對話時段（Session）

一段連續對話構成一個 Session：
1. **進行中**：長者持續對話，AI 即時回覆
2. **關閉中**：準備結束，確認所有對話都已處理完
3. **已關閉**：對話凍結，背景開始整理生活事件

關閉方式有兩種：App 主動關閉（如離開畫面），或系統偵測閒置後自動關閉。

## 資料模型

系統使用五張主要資料表：

### 1. 長者資料 (elders)

儲存長者的個人檔案：
- 基本資料（姓名、年齡、性別）
- 語言偏好（國語/客語，客語還分六種腔調）
- 健康狀況與家庭成員
- 已綁定的照護者

### 2. 對話紀錄 (conversations)

儲存每一輪對話內容與 Session 狀態：
- 長者說了什麼、AI 回了什麼
- 使用的語言與語音檔案
- Session 的生命週期與處理狀態

### 3. 生活事件 (events)

從對話中提取出的具體事件紀錄：
- 七大分類：飲食、活動、睡眠、用藥、身心狀況、安全、其他
- 每筆事件有唯一身分識別，避免重複記錄
- 支援後續補充資訊（如安全事件的詳情更新）

### 4. 每日摘要 (daily_summaries)

每天自動生成的生活總結：
- 七大類各一段描述
- 例行公事完成狀況
- 需要注意的警示
- 標示資料是否完整（是否還有對話尚未處理）

### 5. 例行公事 (routines)

照護者或 AI 設定的定期任務：
- 支援每日、每週、一次性排程
- 採版本化設計（修改不會影響歷史紀錄）
- 完成狀態不存在此表，而是由事件紀錄動態判定

## 智慧功能

### 語音辨識 (ASR)

- 國語：以 Amazon Transcribe 為主
- 客語：支援六種腔調，使用專用模型
- 全程在雲端處理，手機不做辨識

### 語音合成 (TTS)

- 依語言自動選擇合適的語音引擎
- 客語會根據長者設定的腔調合成
- 合成失敗時仍會回傳文字（不影響對話）

### AI 對話大腦

- 使用 AWS Bedrock 的大型語言模型
- 具備長期記憶（記住過去對話）
- 可查詢衛教知識庫（RAG）
- 可即時執行動作（設定提醒、通報安全事件）

### 事件萃取

批次處理時，系統會：
1. 將凍結的對話內容分段處理
2. 從中識別出生活事件
3. 自動去除重複（同一時間段說了同一件事多次只記一筆）
4. 以標準化格式寫入資料庫

## 安全與可靠性

| 機制 | 說明 |
|------|------|
| 重複請求保護 | 網路重送不會造成重複動作 |
| 競爭條件處理 | 多人同時操作不會互相干擾 |
| 失敗重試 | 處理失敗會自動重試，最終失敗會告警 |
| 資料不可變 | 對話關閉後內容凍結，不可篡改 |
| 加密保護 | 傳輸與儲存皆加密 |
| PII 保護 | 個人資料依政策保留與刪除 |

## API 總覽

| 功能 | 端點 | 使用者 |
|------|------|--------|
| AI 對話 | `POST /chat` | 長者 |
| 關閉對話 | `POST /chat/sessions/{id}/close` | 長者 |
| 長者資料管理 | `GET/POST/PATCH /elders` | 兩端 |
| 綁定照護者 | `GET /me`、`POST/GET /elders/{id}/caregivers` | 兩端 |
| 每日摘要 | `GET /summaries`、`POST /summaries/generate` | 照護者 |
| 生活事件 | `GET /events` | 照護者 |
| 例行公事 | `GET/POST/PATCH/DELETE /routines`、`POST /routines/{id}/complete` | 兩端 |
| 統計 | `GET /stats` | 照護者 |

詳細 API 規格請參閱 `docs/api.md`。
