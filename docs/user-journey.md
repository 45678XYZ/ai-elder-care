# 使用者旅程

本文件是長者與照護者旅程的權威入口。完整端到端情境、角色分工、系統資料流、展示證據與實作邊界見 [`docs/deliverables/user-journey.md`](deliverables/user-journey.md)。

核心旅程如下：

- **照護者設定**：完成資料使用同意 → 建立長者與綁定關係 → 設定例行公事。
- **長者日常**：收到提醒 → 一次啟動免手持語音互動 → 回報吃藥並即時完成行程 → 查詢行程與 RAG 衛教資訊。
- **安全事件**：長者提到滑倒等潛在風險 → 系統即時記錄並通知照護者 → 照護者人工確認與介入。
- **離線整理**：結束 session → 萃取一般生活事件、分類與去重 → 產生帶資料完整狀態的每日摘要。
- **照護者追蹤**：查看摘要、警訊、統計與事件時間軸 → 主動關懷並調整後續照護安排。
