# 情境腳本格式規範

本目錄下的對話腳本採用統一格式，兼顧 Live Demo 排練與 tool 覆蓋驗證。

---

## 文件結構

每個情境檔包含以下區塊：

### 1. 前置條件 (Setup)

列出 demo 開始前必須存在的狀態：
- 長者 persona（對應 `data/personas/` 的 JSON）
- 時間設定
- 已存在的 Routines / Events（種子資料）
- Session 狀態（新 session / 恢復 session）

### 2. 對話流程 (Turns)

每個 Turn 採用以下表格：

```markdown
### Turn N

| 項目 | 內容 |
|------|------|
| 長者（必說） | 「......**觸發詞**......」 |
| 觸發詞 | 粗體標記的關鍵字 |
| 預期工具 | `tool_name(param=value)` |
| AI 回應方向 | 不是逐字稿，而是 AI 應該傳達的意思 |
| 驗證點 | 可觀察到的具體結果（畫面變化、DB 寫入） |
| 備用台詞 | 若工具未觸發，長者的第二次嘗試 |
```

### 3. 分支標記

當 AI 回覆可能走不同方向時：

```
⤷ IF AI 主動追問 → 跳 Turn Na
⤷ IF AI 直接確認 → 跳 Turn Nb
```

### 4. 成功標準 (Exit Criteria)

該情境結束時應產生的可觀察結果清單。

---

## 符號說明

| 符號 | 意義 |
|------|------|
| **粗體** | 觸發詞（必須包含在長者台詞中） |
| `code` | 工具名稱或參數值 |
| ⤷ | 分支路徑 |
| ⚠️ | 高風險點或已知限制 |
| 📌 | 演示者操作提示 |
