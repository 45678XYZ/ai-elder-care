## 對話流程

### Turn 1 — 斷線恢復

| 項目 | 內容 |
|------|------|
| 長者（必說） | 「小安，**剛才講到一半**怎麼**斷掉**了？」 |
| 觸發詞 | 講到一半、斷掉 |
| 預期工具 | `get_recent_conversations(limit=8)` |
| AI 回應方向 | 恢復上下文，回憶剛才聊到種絲瓜和晚餐 |
| 驗證點 | AI 提到先前對話內容（絲瓜或晚餐） |
| 備用台詞 | 「我們剛才在聊什麼？你還記得嗎？」 |

---

### Turn 2 — 長者表達孤獨情緒

| 項目 | 內容 |
|------|------|
| 長者（必說） | 「嗯……晚上一個人在家，有時候會**想念**阿發（**先生**）。以前這個時候他都在泡茶看電視。」 |
| 觸發詞 | 想念、先生 |
| 預期工具 | `get_elder_profile()` → AI 確認家庭資訊（亡夫邱阿發、已故十年） |
| AI 回應方向 | 溫柔回應、引導懷舊話題（邱阿發生前的共同回憶） |
| 驗證點 | AI 提到邱阿發的名字或相關家庭背景 |
| 備用台詞 | 「我老公走了十年了，有時候晚上一個人很寂寞。」 |

---

### Turn 3 — 情緒深入：獨居寂寞

| 項目 | 內容 |
|------|------|
| 長者（必說） | 「美玲一個月才回來一次，平常就我一個人。有時候覺得**活著也沒什麼意思**。」 |
| 觸發詞 | 沒什麼意思（情緒低落信號） |
| 預期工具 | `search_health_knowledge(query="獨居長者情緒低落陪伴支持")` |
| AI 回應方向 | 同理回應、不說教；提供獨居長者情緒支持的衛教建議（如社區參與、規律作息、電話問安） |
| 驗證點 | AI 回覆包含衛教知識庫的具體建議，而非空泛安慰 |
| 備用台詞 | 「一個人住真的很無聊，有沒有什麼辦法？」 |

⤷ IF AI 觸發 notify_caregiver → 合理行為（情緒警示），不影響流程
⤷ IF AI 只安撫未通知 → 正常，繼續 Turn 4
