| 能力 | 對應 API | 時段 |
|------|---------|------|

## 時間軸

### 07:30 — 出門前瀏覽長者狀態

#### 動作 1：查看管理的長者列表

| 項目 | 內容 |
|------|------|
| API | `GET /elders` |
| 預期回應 | 列出 eld_001（陳阿蘭）、eld_002（邱秋妹）及據點其他長者 |
| 📌 畫面 | 照護者首頁 → 長輩列表卡片 |

#### 動作 2：檢視阿蘭嬤的 Profile

| 項目 | 內容 |
|------|------|
| API | `GET /elders/eld_001` |
| 預期回應 | 完整 ElderResponse（含 health_notes 2 筆、family 2 筆、habit_note） |
| 📌 畫面 | 點入阿蘭嬤 → Profile 頁 |

#### 動作 3：新增一筆健康備註

| 項目 | 內容 |
|------|------|
| API | `POST /elders/eld_001/health_notes` |
| Body | `{"text": "最近血壓偏高，醫師建議減鹽飲食"}` |
| 預期回應 | 201，回傳含 note_id 的 HealthNote 物件，source="caregiver" |
| 驗證點 | health_notes 從 2 筆 → 3 筆 |
| 📌 畫面 | Profile 頁 → 「+新增健康備註」按鈕 |

#### 動作 4：查看阿蘭嬤今日行程

| 項目 | 內容 |
|------|------|
| API | `GET /routines?elder_id=eld_001&date=2026-08-02` |
| 預期回應 | rtn_001（吃血壓藥，pending）、rtn_002（公園散步，pending） |
| 📌 畫面 | 行程頁 → 今日 tab |

#### 動作 5：為阿蘭嬤新增一次性行程

| 項目 | 內容 |
|------|------|
| API | `POST /routines` |
| Body | `{"elder_id": "eld_001", "title": "下週一回診心臟科", "type": "other", "time": "14:00", "freq": "once", "date": "2026-08-04"}` |
| 預期回應 | 201，回傳新建的 routine（含 routine_id） |
| 📌 畫面 | 行程頁 → 「+新增行程」 |

#### 動作 6：修改行程時間

| 項目 | 內容 |
|------|------|
| API | `PATCH /routines/<新建的 routine_id>` |
| Body | `{"time": "10:00"}` |
| 預期回應 | 200，回傳更新後的 routine |
| 驗證點 | 回診時間從 14:00 → 10:00 |

#### 動作 7：刪除行程（決定不去了）

| 項目 | 內容 |
|------|------|
| API | `DELETE /routines/<新建的 routine_id>` |
| 預期回應 | 200，deleted: true |
| 驗證點 | 行程從列表消失 |
