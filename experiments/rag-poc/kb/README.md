## 內容範圍限制（非授權問題）

以下項目基於內容安全考量，**只收錄原文的一部分**，而非逐字照搬：

- **照顧管理評估量表**：原始量表是給照顧管理專員使用的正式評估工具。收錄版本只說明量表的用途、涵蓋面向與申請方式，刻意不含實際題目與評分標準，並在檔案內明確禁止 AI 依此回答自我評分問題，一律導向撥打 1966 由專員到府評估。
- **長期照護服務對象口腔照護(病患照護版)**：原始 32 頁手冊大量為需搭配照片才能操作的手勢教學（如協助臥床者刷牙的手部姿勢、按摩手法）及專業口腔評估量表。手勢教學脫離照片容易誤導甚至有安全疑慮，評估量表比照上一點僅供專業人員使用，兩者皆未收錄；只保留不需圖片輔助的原則性說明（口腔照護重要性、氟化物使用、安全進食原則、飲食型態分類、潔牙工具、假牙照護）。
